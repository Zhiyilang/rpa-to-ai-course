## 5 节内容
1. **分水岭**：RPA 解决"重复"，AI 解决"不确定"——什么时候用哪个。
2. **影刀实战**：多表合并 / 双表对账 / 网页爬数据，附最小可跑思路。
3. **给 RPA 装大脑**：GPT-4 + 函数调用处理非结构化数据，三个避坑。
4. **从脚本到 Agent**：工具调用、编排、多步任务（拆解 quorumpilot 四智能体框架）。
5. **作品集 + 接单**：34 个工具怎么变成钱——打赏 / 数字商品 / 服务接单 / 企业定制四条路。
